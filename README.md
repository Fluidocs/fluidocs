# Fluidocs
> Recuperação Semântica de Documentos

Concentra os principais requisitos levantados com a prototipação em uma única interface simples, moderna e ágil.

# Tecnologias

- Front-end: TypeScript, React
- Back-end: Python, FastAPI
- Banco de Dados: PostgreSQL, Aerich, TortoiseORM
- Outras Tecnologias: Elasticsearch, Ollama, TesseractOCR, Redis, Celery
