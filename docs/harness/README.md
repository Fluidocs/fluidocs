## Estado da implantação do harness

O estado das etapas e o próximo passo ficam no
[registro da implantação](tarefas/2026-09-10-implantacao-harness.md).
O diagnóstico preserva a inspeção inicial; este índice apenas encaminha às fontes.

Mudanças de escopo ou de regras desta camada seguem a aprovação por etapa
registrada no AGENTS da raiz. Uma aprovação anterior continua válida dentro
do escopo acordado. Registros futuros devem apontar para fontes principais,
sem duplicar PRODUCT, DESIGN ou transformar hipóteses em decisões.
